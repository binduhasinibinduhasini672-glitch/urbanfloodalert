# 🌊 Urban Flood Alert Platform

An AI-driven real-time urban flood risk monitoring and management system built for smart city disaster assessment (Problem ID: S7).

---

## 📌 Features

- **Real-time Risk Assessment**: Dynamically calculates flood risk levels (High, Medium, Low) and risk scores (0–100) based on rainfall intensity (mm) and drainage capacity (%).
- **AI Advisory & Emergency Guidance**: Generates automated actionable recommendations for municipal teams and disaster management units.
- **Geospatial Live Map Integration**: Displays interactive Google Maps centered on the selected target location zone.
- **1-Click Emergency Alert Broadcast**: Allows instant emergency notification dispatch via WhatsApp/SMS during high-risk scenarios.
- **Database Persistence**: Connected with Supabase REST API for logging real-time flood assessment reports.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite, Tailwind CSS / Custom CSS
- **Backend & Database**: Node.js, Supabase (PostgreSQL REST API)
- **Deployment**: Vercel (Frontend), GitHub
